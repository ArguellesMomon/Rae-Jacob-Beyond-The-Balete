# Rootwater Works — image generation brief

Created with the built-in imagegen tool on 2026-10-17. The [structural reference](../artifacts/waterworks-layout-reference.png) was rendered from the earlier map without characters or mutable puzzle objects; [Old Balete Grove](../assets/maps/old-balete-grove-v2.png) supplied the material and pixel-style reference.

The generated 1518 × 1036 output is preserved as [rootwater-works-source.png](../assets/maps/rootwater-works-source.png). Production preparation samples it to 704 × 500 pixels, crops the top-aligned 704 × 480 world, then enlarges with nearest-neighbor sampling to [rootwater-works-v2.png](../assets/maps/rootwater-works-v2.png), 1408 × 960. This vertical adjustment aligns the channels, bridge and lower props with the existing game geometry. [The native sampling](../assets/maps/rootwater-works-native.png) is retained. Only the v2 image is bundled.

Characters, wheel, lost bell, movable branch, lever handle, diagram directions, route labels and mutable bridge cues remain separate code-rendered art. The active and dry channel materials reuse clipped regions of the same environment image.
