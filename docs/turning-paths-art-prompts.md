# Turning Paths — image generation record

Created with the built-in imagegen tool on 2026-10-17. [The prior empty junction](../artifacts/turning-paths-layout-reference.png) supplied the structural reference and [Bamboo Verge](../assets/maps/bamboo-verge-v2.png) supplied material and pixel style.

The first draft had baked clue boards above their interaction points. A second imagegen edit removed all boards, leaving every clue and changing fork sign to code-rendered layers. The selected output is preserved as [turning-paths-source.png](../assets/maps/turning-paths-source.png). Production preparation resamples it to 640 × 540 with nearest-neighbor sampling, crops the top-aligned 640 × 480 world, and enlarges to [turning-paths-v2.png](../assets/maps/turning-paths-v2.png), 1280 × 960. [The native sampling](../assets/maps/turning-paths-native.png) is retained. This vertical normalization aligns the crossbar and fork mouths with the existing ground silhouette. The collision and walkable polygons are unchanged.

Only the v2 image is bundled. No characters, labels, glyphs, progress values or fork signs are baked into it. [The alignment draft](../artifacts/turning-draft-alignment.png) and [navigation review](../artifacts/navigation-turning-review.png) record the relationship between painting and supported ground.
